# Security policy

## Reporting a vulnerability

Email **security@tayet.app**. When GitHub private vulnerability reporting is active on this
repository, you can use that instead.

Please do not open a public issue for a security problem.

Include what you found, how to reproduce it and the impact you expect. We will send an initial
response within 5 business days.

## Scope

This repository and `*.tayet.app`.
